# Admin UI

[English](../admin-ui.md) | Русский

Веб-интерфейс для просмотра процессов и ручного вмешательства. По умолчанию выключен; включается через
`ruslo.admin-ui.enabled=true`. Подключение, настройки и защита через Spring Security — в
[README модуля](../../ruslo-admin-ui/README.md).

## Страницы

- **Дашборд** (`/ruslo`): число процессов в `FAILED`, просроченных и активных, всего и по типам, и узлы движка с
  работающим диспетчером. Процесс просрочен, если он активен и его следующий запуск прошёл больше минуты назад:
  его не подхватывает ни один узел. Счётчик открывает соответствующий список процессов.
- **Список процессов** (`/ruslo/processes`): поиск с фильтрами и запуск нового процесса.
- **Страница процесса**: статус, состояние, переменные, таймеры процесса, последняя ошибка, история состояний и
  диаграмма definition с пройденным путём. Пока процесс выполняется, страница обновляется.

## Действия

Меню Actions на странице процесса показывает все действия; неприменимое к процессу выключено с указанием причины.
Действия — это [операции ручного вмешательства](operations.md#ручное-вмешательство):

| Действие | Операция |
|---|---|
| Retry current step | `resumeFailedProcess`, для процесса в `FAILED` |
| Change state | `moveProcessToState` |
| Send message | `sendMessage`, с JSON payload, проверенным по классу payload |
| Add, edit, remove variable | `setProcessVariable`, `removeProcessVariable` |
| Set, cancel timer | `setProcessTimer`, `cancelProcessTimer`; момент — в часовом поясе браузера |

Каждое действие пишется в лог приложения с именем пользователя.

## Диаграмма процесса

Диаграмма строится по definition: состояния подписаны `ProcessState.description()`, переходы — результатом, именем
сообщения или таймером. Легенда — в [README модуля](../../ruslo-admin-ui/README.md#process-diagram).
